# 🚀 Quiz Generator

A modern AI-powered Quiz Generator that allows users to create interactive quizzes instantly from any topic. Built with a clean UI, responsive design, and a seamless user experience.

🌐 **Live Demo:** https://quiz-generator-buildswithsubhra.netlify.app/

---

## ✨ Features

- 🎯 Generate quizzes on any topic
- 🧠 Multiple-choice questions
- ⚡ Fast and responsive interface
- 📱 Mobile-friendly design
- 🎨 Modern and clean UI
- 🔄 Dynamic quiz generation
- 📊 Instant score calculation
- 🌙 Smooth user experience
